# BookUsers

**Proyecto final – Programación Orientada a Objetos**  
Ingeniería Informática – UNIPAZ  
Grupo D1 – 2026B

## Descripción
BookUsers es una aplicación desarrollada en Java Swing que permite registrar usuarios, consultar sus datos y generar documentos PDF con su información.

## Funcionalidades
- Registro de usuarios.
- Generación automática de username.
- Selección y visualización de fotografías.
- Validación de campos obligatorios y correo electrónico.
- Listado de usuarios registrados.
- Consulta del detalle de cada usuario.
- Generación de archivos PDF con los datos y la fotografía.
- Ventana de créditos.

## Tecnologías utilizadas
- Java 21.
- Java Swing.
- IntelliJ IDEA.
- OpenPDF 2.0.3.

## Cómo ejecutar el proyecto
1. Abrir el proyecto en IntelliJ IDEA.
2. Verificar que esté configurado el JDK 21.
3. Abrir la clase `FormMenu.java`.
4. Ejecutar el método `main`.
